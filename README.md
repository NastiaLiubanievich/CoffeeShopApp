# CoffeeShopApp 

Система управління кав'ярнею, розроблена на C# з використанням WPF, Entity Framework Core та SQL Server.

## Опис проєкту

Додаток призначений для автоматизації роботи кав'ярні. Програма дозволяє переглядати меню, формувати замовлення, розраховувати загальну суму та зберігати інформацію про замовлення в базі даних.

## Основні можливості

- Перегляд меню товарів
- Фільтрація за категоріями
- Додавання товарів до замовлення
- Автоматичний підрахунок суми
- Збереження замовлень у базу даних
- Перегляд історії замовлень
- Управління товарами та категоріями
- Формування звітів

## Технології

- C#
- WPF
- .NET 8
- Entity Framework Core
- SQL Server LocalDB

## Структура проєкту

- `Models` — моделі даних
- `Data` — DbContext та робота з базою даних
